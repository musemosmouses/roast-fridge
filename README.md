# Roast the Smart Fridge: One Line, Best Laugh Wins

One line roasting the smart fridge: it judges my midnight snacks, emails me
a health report, and still can't tell the kale from the science experiment
growing beside it.

Built for [Roast the Smart Fridge](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9)
on [make.fun](https://make.fun) — referral: https://make.fun/r/w3zshnah

## The entry

> My smart fridge judges my midnight snacks, emails me a health report, and still can't tell the kale from the science experiment growing beside it.

146 characters, plain ASCII, one line, one sentence, no setup.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22). Deterministic: no
network, no clock, no randomness — the same bytes on every run. The program
writes exactly the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`
when the variable is unset), with no trailing newline.
